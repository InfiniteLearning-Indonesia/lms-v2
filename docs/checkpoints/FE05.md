## 1. Tujuan

FE05 menyiapkan presentation dan interaction boundary untuk completion, transcript, dan credential tanpa memindahkan policy akademik atau authority penerbitan ke browser.

- Student memahami progress Activity/Class dan evidence yang terpenuhi, hilang, waived, atau dibuka kembali.
- Teacher meninjau projection Student dan correction history tanpa memakai global role sebagai authorization.
- Transcript disajikan sebagai immutable snapshot dengan policy/provenance.
- Certificate eligibility, issue, revoke, supersede, download, dan public verification tetap merupakan lifecycle terpisah.

FE01–FE04 tetap `BLOCKED_BACKEND`. Memulai FE05 tidak menyatakan M07, M09, M10, identity/session, atau HTTPS integration selesai.

## 2. Keputusan product dan UX

### 2.1 Information architecture

- `/app/classes/[classId]/progress` melayani projection Student atau Teacher berdasarkan payload actor-scoped.
- Progress tidak dikembalikan sebagai menu sidebar. Entry point kontekstual tersedia dari `/learning` bila `progress.read` diizinkan.
- `/app/classes/[classId]/credentials` menampilkan transcript snapshot dan certificate lifecycle.
- `/certificate/verify/[code]` adalah surface publik data-minimal; production menampilkan dependency state sampai lookup M10 tersedia.
- Student dan Teacher tidak memakai role toggle. Backend harus mengirim projection yang sesuai, bukan seluruh roster Teacher ke Student lalu disembunyikan dengan CSS.

### 2.2 Completion semantics

- Activity complete, Class complete, pass, transcript release, certificate eligible, dan certificate issued adalah keputusan berbeda.
- `progressPercent` dipresentasikan dari server. Browser tidak menghitungnya dari jumlah card, submission state, atau grade.
- Grade tinggi tidak otomatis complete; complete tidak harus memiliki grade; waived evidence tidak dibuat menjadi nilai.
- Override/reopen membutuhkan capability canonical, reason, optimistic version, audit, idempotency, dan command receipt.
- Correction membuat outcome version baru dan tidak memperbaiki data melalui GET atau render side effect.

### 2.3 Transcript dan credential

- Transcript adalah snapshot immutable dengan raw/scale/policy provenance dan explicit Class-scoped release.
- Regrade/correction tidak menimpa snapshot atau certificate lama.
- Issue bersifat explicit dan idempotent; retry/replay tidak boleh menghasilkan certificate ganda.
- Revoke dan supersede mempertahankan identifier/history lama.
- Legacy release flag hanya ditampilkan sebagai historical provenance bila backend membedakannya; tidak boleh difabrikasi menjadi issuance event.
- Public verification tidak membawa email, grade detail, evidence privat, enrollment history, atau internal student ID.

## 3. Scope

### Masuk FE05

- Typed completion, transcript, credential, dan public verification view model dengan Zod validation.
- Exact Class ancestry, actor projection, provisional capability seam, dan development fixture server-only.
- Student Activity/Class progress, evidence explanation, waiver, missing evidence, dan CTA ke Credentials.
- Teacher roster search/filter, detail evidence, policy/outcome version, correction, dan disabled override/reopen controls.
- Transcript snapshot, provenance, grade display yang sudah dirilis, correction state, eligibility, certificate lifecycle, dan disabled authoritative actions/download.
- Public valid/revoked/superseded/not-found/dependency presentation dengan data minimum.
- Loading/dependency, empty, forbidden, foreign Class, responsive, keyboard, dark/reduced-motion, production fail-closed, unit/component, build/bundle, dan Playwright.

### Di luar FE05

- Menentukan completion policy atau menghitung outcome/eligibility di browser.
- Mengimplementasikan M07, M09, M10, file delivery, signing, QR, PDF certificate design, atau backend repository.
- Attendance/logbook evidence intake milik FE06 kecuali nanti M10 policy mengkonsumsinya melalui contract canonical.
- Reporting/export/migration operations milik FE07.
- Browser storage untuk outcome, transcript, certificate, token, receipt, atau private file URL.
- Endpoint, payload, capability, certificate URL, atau successful mutation yang tidak ada pada OpenAPI.

## 7. Stop condition

- Final override/reopen/release/issue/revoke/supersede/download tetap disabled sampai contract canonical, CSRF, capability, version, idempotency, receipt, dan private file access tersedia.
- Jangan menghitung completion/pass/eligibility dari grade, jumlah UI card, atau jam browser.
- Jangan expose Teacher roster atau foreign Class resource melalui projection Student.
- Jangan overwrite outcome, transcript snapshot, issued credential, atau correction history.
- Jangan menyebut certificate valid/issued atau file siap diunduh tanpa response authoritative.
- Public verification production tidak memakai fixture, guessed status, atau data privat.
