## 1. Tujuan

FE02 membangun pengalaman frontend untuk administrasi Class dan participation tanpa mengubah backend atau mengarang read model production. Fokus utama adalah Site Admin, dengan contextual control Teacher untuk Student bila capability backend kelak mengizinkan.

FE01 tetap `BLOCKED_BACKEND`; memulai FE02 tidak mengubah login, session, atau integration evidence FE01 menjadi selesai.

## 2. Scope yang dibekukan

- `/app/admin/classes`: direktori, pencarian/filter lifecycle, mobile card/desktop table, dan form create Class nama-first.
- `/app/classes/[classId]/settings`: metadata, version awareness, dan lifecycle publish/close/reopen/archive.
- `/app/classes/[classId]/people`: participant directory, pencarian/filter, add Teacher/Student, participation actions, dan history UI.
- Typed transport hanya untuk path M05 yang sudah ada pada snapshot OpenAPI.
- Typed UI-facing adapters dan development fixtures untuk read model yang belum tersedia.
- Production menampilkan dependency state; preview tidak memalsukan mutation sukses.

Di luar scope: self-enrollment, katalog global/enroll key, identity provisioning, grouping/personal mentor, invited/retake, content-ready publish, materi, tugas, penilaian, attendance, dan logbook.

## 3. Audit kontrak masuk

Snapshot `cp11-cp12` menyediakan:

- `POST /classes`, `GET/PATCH /classes/{class_id}`;
- `EditClass.version` wajib dan minimal `1`; lifecycle command memakai body `Version` yang juga wajib;
- `POST` publish/close/reopen/archive dengan version;
- `POST /classes/{class_id}/participants` untuk Teacher/Student;
- `POST` suspend/reactivate/end participant.

Belum tersedia:

- admin Class listing dan `/me/classes`;
- participant list/search/history;
- identity directory/search;
- bulk preview;
- contextual roles/capabilities pada canonical Class response;
- browser-safe CSRF bootstrap/refresh.

Contract versioning sudah ada pada payload write, tetapi belum sepenuhnya ketat pada response: schema `Class` belum menandai `version` sebagai required sehingga generated type masih opsional, dan response `409` lifecycle/edit belum memiliki structured error body dengan `current_version`. Frontend read adapter sementara mewajibkan version dan harus fail closed bila field tersebut hilang; integrasi final memerlukan pengetatan contract response ini.

Backend M05 baru memiliki 2/5 slice teruji lokal. Full canonical M05 tetap belum lulus; frontend tidak menaikkan status backend.

## 6. Stop condition

- Jangan mengubah `api-lms-v2` dari pekerjaan ini.
- Jangan membuat GET/list/search/history endpoint yang tidak ada pada OpenAPI.
- Jangan mengaktifkan mutation preview atau menampilkan toast sukses tanpa authoritative response.
- Jangan menerima raw `user_id` sebagai UX production pengganti identity search.
- Jangan memakai Site Admin/Teacher label sebagai pengganti capability backend.
- Jangan mengaktifkan mutation sebelum CSRF, response capability, version, dan error contract aman.
- Jangan mengimplementasikan self-enrollment, group/mentor, invited/retake, atau content-ready publish di FE02.
