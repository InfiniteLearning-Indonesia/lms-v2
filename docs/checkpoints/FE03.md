## 1. Tujuan

FE03 menyiapkan pengalaman menyusun dan mengakses pembelajaran di dalam satu Class tanpa memindahkan ownership, authorization, sanitization, revision, availability, atau file policy ke browser.

Hasil yang dituju setelah implementasi diotorisasi:

- Pengajar menyusun Section dan Activity, mengatur urutan, meninjau readiness, lalu melakukan draft/publish/withdraw melalui capability dan response backend.
- Student membaca activity yang telah tersedia dan mendapat alasan yang jelas ketika content terkunci, belum tersedia, ditarik, atau prerequisite belum terpenuhi.
- File material tetap private, Class-scoped, dan hanya dapat diakses setelah policy, scan, serta authorized access backend mengizinkan.
- Revision yang sudah dipakai learner tidak ditimpa diam-diam saat content diperbarui.

UI-first slice telah diimplementasikan setelah persetujuan 13 September 2026. Implementasi ini tidak menaikkan status M06/M07 dan tidak mengubah status FE01/FE02 yang masih `BLOCKED_BACKEND`.

## 2. Keputusan product dan UX yang dibekukan

### 2.1 Information architecture

- Route resource utama tetap `/app/classes/[classId]/learning`. Deep-link editor `/learning/activities/[activityId]/edit` dan create `/learning/activities/new?sectionId=…&type=…` adalah route UI provisional yang fail closed; query hanya membawa identity Section dan enum tipe non-sensitif, sedangkan title/description/content tidak diletakkan pada URL. Identity resource, read path, dan mutation semantics tidak dianggap canonical sebelum contract M06–M07 dibekukan.
- Hirarki awal adalah satu tingkat `Section → ordered Activity`. Arbitrary nested folder tidak diasumsikan.
- Actor dengan capability authoring membuka halaman utama sebagai **Preview Student Mode** yang informatif, bukan toggle mode. Draft/status author-only tetap ditandai jelas dan tidak mengubah authorization context.
- Setiap Activity menyediakan CTA **Edit** kontekstual pada ujung kanan title hanya bila `content.manage` tersedia. CTA membuka deep link editor `/learning/activities/[activityId]/edit`.
- Setiap Section menyediakan control **Edit** dan **Hapus** pada header hanya bila `content.manage` tersedia; CTA **Tambah Section** berada setelah Section terakhir. Form create/edit menampung nama serta deskripsi opsional dan dapat ditinjau, tetapi final save tetap disabled sampai command contract tersedia. Hapus memakai confirmation dialog dan aksi final tetap disabled sampai backend membekukan cascade/empty-only, published revision, serta version-conflict semantics.
- CTA **Tambah Activity** berada di akhir setiap Section hanya bila `content.manage` tersedia. Section kosong tetap menampilkan rectangle **Tidak Ada Activity** dan CTA authoring secara terpisah. Dialog mengikat calon Activity ke Section dan meminta tipe `MATERIAL` atau `ASSIGNMENT`, lalu membuka halaman create khusus berisi title, description/ringkasan, structured editor, dan attachment shell. Tipe lain, order, lifecycle awal, version, ID, payload, dan receipt tidak diasumsikan sebelum OpenAPI M07 tersedia; final save tetap disabled.
- Editor Activity berdiri pada halaman terpisah dan langsung menampilkan Detail Activity, conflict, field edit, lifecycle action, structured editor, serta attachment/private file. Editor tidak mengulang preview content maupun control posisi.
- Student memperoleh surface belajar tanpa label mode: daftar Section, status Activity, availability reason, dan area baca yang menjaga panjang baris content sekitar 65–75 karakter. Label **Preview Student Mode** hanya muncul untuk actor authoring.
- Site Admin tidak otomatis menjadi content author hanya karena role global. Control hanya muncul dari contextual capability Class.
- Policy UI memisahkan izin manage structure, reorder, edit Activity, lifecycle, dan upload. Selama capability M07 belum canonical, fixture memetakan manage structure/reorder/edit ke `content.manage`; pemetaan provisional ini wajib diganti dari response contract tanpa mengubah komponen presentasi.
- Facilitator dan Student tidak memperoleh control mutasi content secara default.
- Pembelajaran dibuka dari CTA kontekstual pada Ringkasan Class, bukan dari menu sidebar. Saat route `/learning` atau turunannya aktif, sidebar dan drawer navigasi tidak dirender agar mentor maupun Student dapat fokus pada isi.
- Focused learning workspace menyediakan satu jalur keluar yang konsisten, **Kembali ke Ringkasan Class**, serta tetap mempertahankan deep link dan capability guard `content.read`.
- FE03 tidak menghidupkan kembali menu Progress yang sebelumnya dihapus.

### 2.2 Pola interaksi

- Pengajar memilih Activity dari daftar untuk membaca preview, lalu membuka editor khusus melalui CTA di header Activity. Preview dan data-entry tidak ditumpuk dalam satu halaman.
- Card Activity memenuhi lebar kolom outline agar target interaksi stabil dan tidak berubah mengikuti panjang judul.
- Reordering hanya dibuka dari tombol **Edit Urutan** yang sejajar dengan judul **Susunan pembelajaran**. Mode ini mengganti sementara control create/edit/delete dengan control **Naik/Turun** untuk Section dan Activity agar tugas pengguna tetap fokus. Drag-and-drop hanya progressive enhancement, bukan satu-satunya cara.
- Modal Edit Section tidak menduplikasi control reorder. Satu pintu ini mencegah urutan lokal berbeda antara modal dan outline serta menjaga version-conflict ditangani oleh satu command contract.
- Control urutan mempunyai nama aksesibel, mempertahankan konteks fokus keyboard setelah item berpindah, menonaktifkan arah yang invalid, dan tidak memindahkan Activity lintas Section. **Batal Edit Urutan** mengembalikan susunan fixture; final save tetap disabled sampai version dan command receipt backend tersedia.
- Satu konteks hanya memiliki satu primary action. Save draft, publish, dan withdraw harus berbeda secara visual serta memerlukan readiness/confirmation yang relevan.
- Perubahan belum tersimpan, request in-flight, conflict, dan hasil authoritative harus dibedakan. Navigasi tidak boleh menghilangkan draft lokal tanpa peringatan.
- Loading mempertahankan ruang agar layout tidak melompat. Error ditempatkan dekat sumber masalah, diumumkan secara aksesibel, dan selalu menyediakan recovery yang valid.
- Semua icon interaktif mempunyai accessible name, tab order mengikuti urutan visual, target sentuh minimum 44 × 44 px, dan focus tidak bergantung pada warna saja.
- Seluruh copy baru memakai katalog `next-intl` Bahasa Indonesia.

### 2.3 Activity awal dan batas FE04

- UI harus dapat merender activity type dari kontrak, termasuk fallback aman untuk type yang belum dikenal.
- Materi dapat menampilkan canonical rich content dan attachment yang diizinkan.
- Assignment pada FE03 hanya mencakup definisi content, availability, due/cutoff, attachment, dan entry point pembelajaran.
- Draft submission, attempt, revision karya Student, receipt, grading, rubric, release nilai, dan AI grading tetap FE04. FE03 tidak membuat simulasi submit atau nilai.

## 4. Audit kontrak masuk dan dependency backend

Snapshot OpenAPI `cp11-cp12` saat brief dibuat hanya memuat identity/session lokal serta sebagian Class/participation. Tidak ada path atau schema canonical untuk Section, Activity, content revision, availability, FileAsset, upload, scan, maupun authorized download.

Backend M06 dan M07 sama-sama masih `NOT_STARTED`/`NOT_RUN`. Karena itu frontend tidak boleh mengarang path, query key, payload, response, reason code, atau mutation success sebagai kontrak production.

Contract handoff minimum yang dibutuhkan sebelum integration:

| Area | Contract canonical yang dibutuhkan |
|---|---|
| Resource identity | Class-owned Section, Activity, revision, attachment, dan FileAsset ID; ancestry serta ownership eksplisit |
| Reads | Ordered Section/Activity list, activity detail/revision, learner availability, attachment status, dan stable ordering |
| Commands | Create/edit Section dengan title dan optional description; create/edit Activity dengan parent Section, type, title, optional summary, structured content, initial placement/lifecycle; reorder terpisah; publish/withdraw, attach/detach, upload intent/finalize/cancel dengan version atau ETag |
| Capability | Read, author, reorder, publish, withdraw, upload, dan download capability yang contextual; role label bukan authorization. Mapping fixture `content.manage` bukan nama canonical backend. |
| Revision | Published revision immutable, latest/current revision, stale `409`, `current_version`, dan historical reference semantics |
| Content safety | Canonical structured content, sanitizer/allowlist contract, allowed URL/embed policy, serta raw unsafe source tetap restricted |
| Availability | Machine-readable reason code, display-safe parameters, prerequisite reference, start/due/cutoff timestamp, dan server timezone |
| File policy | Accepted type/extension, maximum size/count, checksum/metadata, private object identity, expiry, dan backend-authoritative MIME/magic-byte result |
| File lifecycle | Intent expiry, upload method/fields, retry/cancel semantics, scan state, quarantine/reject reason, ready state, dan attach eligibility |
| Access | Authorized download response, bounded expiry, denial reason, audit semantics, dan tidak ada public fallback |
| Errors | Typed `401/403/404/409/413/415/422/429/503`, `request_id`, field errors, retry-after, current version, dan safe recovery detail |
| Browser security | Same-origin cookie credentials, browser-safe CSRF bootstrap/refresh, idempotency, no Bearer, dan no secret pada URL/storage/log |

Cursor/filter contract hanya ditambahkan bila backend memang memerlukan pagination. Frontend tidak menetapkan offset/cursor atau sort syntax sebelum OpenAPI tersedia.

## 5. UX state model

### 5.1 Content dan authoring

| State | Presentasi dan aksi |
|---|---|
| Dependency unavailable | Jelaskan integrasi content belum tersedia; tidak render fixture atau mutation control pada production |
| Loading | Skeleton menjaga hierarchy dan reading area tanpa layout shift |
| Successful empty | Pengajar dengan capability mendapat CTA membuat Section; Student mendapat pesan belum ada materi dipublikasikan |
| Loaded | Section dan Activity berurutan, card Activity selebar kolom, status tidak hanya dibedakan lewat warna, selected item terlihat jelas |
| Draft | Hanya actor berwenang; Student tidak boleh menerima draft melalui UI maupun response |
| Scheduled/locked | Tampilkan reason dan waktu lokal dari timestamp server; jangan menghitung policy authorization di browser |
| Prerequisite unmet | Tampilkan prerequisite yang aman dan langkah berikutnya tanpa membocorkan resource asing |
| Published | Student dapat membaca revision yang diizinkan; perubahan baru tidak me-repoint historical reference |
| Withdrawn/read-only | Content tetap dapat dijelaskan sesuai policy tanpa menawarkan aksi yang tidak valid |
| Unsaved | Label perubahan belum tersimpan dan navigation warning; bukan badge sukses |
| Stale conflict | Tampilkan versi terbaru dan pilihan review/reload; tidak silent overwrite atau auto-merge semu |
| Forbidden/not found | Bedakan `403` dari session expiry; jangan bocorkan keberadaan foreign Class/resource |
| Retryable failure | Pesan dekat control, `request_id` bila tersedia, dan retry memakai intent/idempotency yang benar |

### 5.2 Private file

| State | Presentasi dan aksi |
|---|---|
| Selected | Nama, ukuran, dan type yang dilaporkan browser; belum disebut aman atau uploaded |
| Client-invalid | Advisory error di dekat picker; backend tetap authority untuk MIME, magic-byte, size, dan scan |
| Waiting for intent | Upload disabled dengan alasan dependency bila contract/session/CSRF belum siap |
| Uploading | Status nyata; persentase hanya bila bytes sent/total benar-benar tersedia, bukan timer palsu |
| Processing/scanning | Status indeterminate yang dapat diumumkan tanpa live-region spam |
| Ready | Attachment baru dapat dipilih/diakses setelah backend menyatakan ready dan policy mengizinkan |
| Quarantined/rejected | Alasan aman, tanpa preview active content; sediakan replace/remove atau bantuan sesuai capability |
| Failed/expired | Recovery eksplisit; expired access meminta authorized access baru, bukan menyimpan atau memakai ulang URL lama |
| Removed/detached | Konfirmasi relasi attachment berubah; tidak mengklaim object fisik terhapus |

## 9. Stop condition

- Jangan melanjutkan ke production integration sebelum contract M06–M07 direview dan snapshot OpenAPI diperbarui dari backend source yang sah.
- Jangan mengubah repository backend dari pekerjaan frontend FE03.
- Jangan mengarang endpoint/schema atau menyalakan production transport sebelum contract canonical tersedia.
- Jangan menurunkan authorization dari role label, menyimpan Class context hanya di browser, atau mempercayai preview mode sebagai security boundary.
- Jangan memakai `dangerouslySetInnerHTML` untuk raw content atau menampilkan restricted original content.
- Jangan mengunggah base64/data URL, memakai public object URL, menyimpan signed URL, atau menyebut file aman sebelum scan backend selesai.
- Jangan menampilkan progress/publish/save sukses palsu, optimistic authoritative success, atau menghilangkan conflict.
- Jangan membocorkan draft, attachment, prerequisite, atau resource lintas Class.
- Jangan memperluas FE03 ke submission, grading, completion/progress, enrollment, logbook, attendance, clone/import, atau outbound fetch UI.
