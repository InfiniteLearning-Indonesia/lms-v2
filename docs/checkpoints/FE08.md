## 1. Tujuan

FE08 menutup UI-first roadmap dengan public surface yang jujur, konsistensi UX lintas checkpoint, accessibility dan browser matrix, performance/security baseline, serta release evidence. FE08 tidak mengubah slice FE01–FE07 yang backend-blocked menjadi integrated atau production-ready.

Backend lokal masih berada pada `52cbc88`: M04–M05 hanya partial local dan M06–M18 belum tersedia. Karena itu final production smoke, real health, strict identity-owner CSP allowlist, penghapusan compatibility layer yang masih dibutuhkan, dan release approval tidak boleh direkayasa dari fixture.

## 2. Keputusan yang dibekukan

- Landing dan Status merupakan Server Components; copy masuk katalog `next-intl` dan tidak memerlukan request bisnis.
- Halaman Status membedakan UI availability, identity bridge, backend domain, dan real HTTPS journey. Tidak ada label “Operational” tanpa health contract authoritative.
- Login tetap disabled. Landing hanya mengarahkan ke halaman login/status dan tidak memanggil challenge.
- Security header baseline boleh diperketat selama same-origin transport, local font, Next runtime, dan future identity-owner redirect tidak rusak. Allowlist pihak ketiga tidak ditebak.
- Automated axe tetap gate; keyboard, 375 px, landscape, dark, reduced motion, dan text scaling dipertahankan.
- Chromium menjalankan seluruh regression. Firefox dan WebKit menjalankan public/login smoke yang kecil dan deterministik.
- Bundle budget mengukur output production aktual. Budget bukan pengganti field Core Web Vitals atau load test.
- Source legacy yang tidak berada pada runtime tetap diinventarisasi. File aktif yang tidak lagi dipakai boleh dihapus; archive `legacy/` baru dihapus setelah final migration/reference approval.
- Tidak ada endpoint, capability, health response, monitoring data, atau success state yang dibuat khusus untuk meluluskan FE08.

## 3. Scope

### 3.1 Dikerjakan sekarang

- Landing dan Status responsif dengan hierarchy, skip link, theme, metadata, serta status integrasi yang eksplisit.
- Root 404 dengan recovery path.
- Konsistensi minimum touch target, focus, contrast, reduced motion, dan semantic state.
- Header security production: content type, frame denial, referrer, permissions, opener, cross-domain policy, dan CSP baseline. HSTS/HTTPS upgrade tetap tanggung jawab edge TLS deployment agar local HTTP dan reverse-proxy topology tidak dirusak oleh aplikasi.
- Route bundle budget dan forbidden client bundle scan.
- Axe pada Landing/Status/Login/Admin dependency surface.
- Full Chromium regression serta Firefox/WebKit public smoke.
- Cleanup komponen mati dan lint coverage untuk theme components aktif.
- Sinkronisasi checkpoint/status/handoff.

### 3.2 Tetap diblokir

- Health/status real-time, incident history, uptime, atau maintenance feed tanpa kontrak backend.
- Strict nonce CSP dan final identity-owner allowlist sebelum browser bridge/deployment topology tersedia.
- Field Core Web Vitals, production observability, HTTPS deployment smoke, dan external monitoring evidence.
- Penghapusan archive legacy atau compatibility layer yang masih diperlukan untuk migration reference tanpa approval final.
- Final release approval dan perubahan status FE01–FE08 menjadi `COMPLETED`.

## 6. Stop condition

- Hentikan aktivasi fitur jika membutuhkan endpoint/capability/health field yang tidak ada di OpenAPI canonical.
- Jangan menghapus archive legacy bila masih menjadi satu-satunya migration/reference evidence.
- Jangan menurunkan CSP/header hanya agar test fixture pihak ketiga yang tidak canonical dapat berjalan.
- Jangan menandai FE08 completed hanya karena build dan browser mock/local lulus.
- Jangan commit, push, deploy, mengunduh production data, atau mengubah backend tanpa otorisasi pengguna.
