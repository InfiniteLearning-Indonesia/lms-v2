## 1. Tujuan

FE04 menyiapkan alur Student menyusun dan mengumpulkan tugas serta alur Teacher meninjau, menilai, dan merilis hasil tanpa memindahkan authority submission, deadline, receipt, rubric, grade, import, atau AI ke browser.

- Student melihat Assignment, server draft, revision, feedback, due/cutoff, receipt, dan immutable timeline.
- Teacher menggunakan inbox submission, menilai revision yang tepat melalui rubric version, serta membedakan draft/final/released.
- Import selalu melalui preview terikat actor/Class/input/policy sebelum explicit commit.
- AI hanya memberikan suggestion ber-provenance; Teacher wajib meninjau dan tidak ada auto-grade atau fallback score.

FE03 tetap `BLOCKED_BACKEND 6/8`. Memulai FE04 tidak menyatakan M06–M09 maupun identity/session integration selesai.

## 2. Keputusan product dan UX

### 2.1 Information architecture

- `/app/classes/[classId]/submissions` menampilkan pekerjaan Student atau Teacher inbox berdasarkan actor-scoped projection dan contextual capability.
- `/app/classes/[classId]/gradebook` menampilkan Assignment, daftar Student, rubric, grade history state, import preview, dan AI suggestion kepada actor yang diizinkan.
- Assignment yang tersedia pada `/learning` mempunyai entry point menuju Pengumpulan; definisi content tetap milik FE03, karya learner milik FE04.
- Student dan Teacher tidak memakai toggle role. Backend memberikan projection yang sesuai; frontend tidak mengirim seluruh inbox Teacher ke Student lalu menyembunyikannya dengan CSS.
- Daftar dan detail memakai master-detail responsive: satu kolom pada viewport sempit, dua kolom pada desktop.
- Capability fixture yang tersedia belum canonical untuk mutation. Adapter sementara memakai `submission.read`/`gradebook.read` untuk read serta `content.manage` untuk mengenali author fixture. Mapping ini wajib diganti saat M08–M09 memublikasikan capability canonical.

### 2.2 Submission semantics

- Browser tidak menentukan due/cutoff/late/locked. UI hanya mempresentasikan deadline state serta timestamp server dalam timezone Class.
- Draft browser adalah perubahan lokal, bukan server draft dan bukan sukses tersimpan.
- Submit/resubmit harus menghasilkan durable receipt dengan waktu server serta idempotency semantics; timeout tidak boleh membuat revision ganda.
- Setiap resubmit menambah immutable revision. Teacher menilai `submissionRevision` eksplisit; karya lama tidak ditimpa atau di-repoint.
- Attachment tetap mengikuti private FileAsset M06. Nama file yang dipilih belum berarti uploaded, ready, atau aman.

### 2.3 Gradebook, import, dan AI

- Rubric memiliki version, criterion, bounds, dan maximum score yang tervalidasi backend.
- Grade mempunyai `UNGRADED → DRAFT → FINAL → RELEASED`; release adalah perintah eksplisit.
- Regrade memerlukan alasan dan version conflict handling. Nilai released hanya baca pada UI-first fixture.
- Import menampilkan valid/invalid/unchanged rows, policy version, issue, dan expiry sebelum commit. Preview tidak mengubah nilai.
- AI suggestion dapat diterapkan ke draft lokal setelah tindakan Teacher, tetapi tidak otomatis tersimpan, difinalisasi, atau dirilis.
- Provider failure ditampilkan eksplisit dan tidak menghasilkan fallback nilai.

## 3. Scope

### Masuk FE04

- Typed actor-scoped submission dan gradebook read model, schema validation, exact Class ancestry, dan capability adapter seam.
- Student assignment list, answer/attachment shell, local dirty state, unsaved warning, receipt, feedback, revision timeline, due/cutoff, dan locked/read-only states.
- Teacher inbox dengan summary, pencarian, filter Assignment/status, submission detail, attachment, receipt, dan handoff ke grading.
- Rubric scoring, total lokal yang bounded, feedback, regrade reason, grade lifecycle, released read-only, import preview, serta human-reviewed AI suggestion.
- Loading/dependency, successful empty, forbidden, actor projection mismatch, foreign Class, responsive, keyboard, and production fail-closed states.
- Unit/component tests, fixture validation, production build, bundle scan, dan Playwright production journey.

### Di luar FE04

- Content builder/private file completion milik FE03; completion/transcript/certificate milik FE05.
- Attendance, permission, SP, logbook, group, dan personal mentor milik FE06.
- Quiz engine, plagiarism, peer review, anonymous marking, manual global score broadcast, atau AI finalization.
- localStorage/sessionStorage/IndexedDB sebagai authoritative draft, token, receipt, grade, atau signed URL store.
- Endpoint/payload/capability baru yang tidak berasal dari OpenAPI backend.
- Perubahan repository backend, deployment, atau provider call nyata.

## 7. Stop condition

- Final mutation tetap disabled sampai contract canonical, CSRF, capability, version, idempotency, dan receipt tersedia.
- Jangan menghitung authorization atau deadline dari role/jam browser.
- Jangan expose Teacher inbox/gradebook melalui projection Student atau resource foreign Class.
- Jangan overwrite revision, mengubah nilai saat preview import, atau auto-apply/auto-release AI suggestion.
- Jangan menyebut local draft tersimpan, file aman, submit berhasil, atau grade authoritative tanpa response backend.
- Jangan memperluas scope ke completion, credential, attendance, logbook, atau backend implementation.
